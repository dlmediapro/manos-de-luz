## 🌟 Resumen de Entregables Vectoriales (`05_Identidad_Vectorial/`)

## 🎨 Paleta Cromática "Abrazo Artesanal"

- **Crema Algodón (`#F7F4EE`):** 60% — Lienzo principal, paz y descanso visual.
- **Avena Tibia (`#E8DDD0`):** 25% — Fondos secundarios y tarjetas de producto.
- **Cacao Profundo (`#4A3525`):** 25% — Textos principales, menús y contornos de máxima legibilidad (10.47:1 AAA).
- **Verde Oliva Suave (`#8C9A7E`):** 10% — Manos protectoras, equilibrio y sellos de calidad artesanal.
- **Terracota Rosado (`#C86D63`):** 5% — Corazón tejido, botones de conversión y acentos emotivos.
